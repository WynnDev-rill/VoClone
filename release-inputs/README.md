# One-time verified owner APK transport

The cloud integration can push source and dispatch Actions, but `uploads.github.com` returned 401 when uploading Release assets. The manually dispatched publication workflow checks out source commit a06b3005bbc80ee86e248b9a48c5924d372d11e4, verifies this already signed APK against its recorded hash and owner certificate, reconstructs corresponding native source, then publishes through GitHub's own runner token.

This is a transport step, not a claim that Actions rebuilt or signed the owner APK. The normal Android workflow builds/tests debug and supports future signed rebuilds using the four owner Secrets. No private signing key, password or model weight is included. The transport APK and one-time workflow were removed from the current branch after successful publication. Historical commit1b953f63a25cbcc47ab66939ee3abf4f8357090f retains the transport procedure. Release: https://github.com/WynnDev-rill/VoClone/releases/tag/v0.1.0-alpha ; successful Actions publication: https://github.com/WynnDev-rill/VoClone/actions/runs/41148356729 . The ordinary Android workflow remains the path for future signed rebuilds after the owner configures Secrets.
