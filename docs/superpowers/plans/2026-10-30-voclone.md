# VoClone implementation plan
User delegates engineering decisions and explicitly requests autonomous implementation, so no approval gate is added.

1. Audit VoiceStudio native cloning, model catalogue/licences and ScreenGuard updater. Compare VoiceStudio, ElevenLabs, Chatterbox, F5-TTS, XTTS. Pin sources and weights independently. Tests: digest and manifest rejection.
2. One Android app module plus native runtimes. NativeEngine serializes Whisper then OmniVoice (never both contexts resident). ModelStore downloads pinned assets using resumable HTTP Range, SHA-256 and atomic rename. A foreground CoroutineWorker owns long tasks and cancellation.
3. Test audio/reference validation, resampling/WAV, profile transaction failure, model corruption/resume, updater host/package/version/signer mismatch before implementation. Native Android MediaExtractor/MediaCodec decodes imported MP3/WAV; AudioRecord captures mono PCM. LAME exports MP3.
4. Reference workflow: sample -> actual transcript (editable) -> actual synthesized preview -> WAV validation -> atomic profile commit. Generation uses stored reference+transcript and verifies output before success. Restart/crash retains only complete profiles/results.
5. Compose surface follows DESIGN.md; settings models/licences/theme/updater. Play/seek, rename/delete/recreate/use, WAV/MP3 document export and FileProvider share. No cloud routes or fake UI records.
6. CI tests/lint/build debug ARM64 and securely signed release. Generate owner key outside git; configure repository secrets; supply private backup. Update channel on public Wynn-Store (private source repo remains private); supply corresponding AGPL source with APK. Stable release remains gated on physical-device E2E evidence; alpha is labelled.
7. Run actual host OmniVoice E2E with pinned model and reference; device instrumentation covers JNI/audio/storage/UI where emulator available. Build graph with official Graphify CLI; query dependencies and refresh after changes. Review and document exact verified/unverified status.

Review focus: process death, cancel during JNI, corrupt/oversized media, interrupted downloads, model licence changes, package signer mismatch, app-private path traversal, disk full, low memory, Android 16 foreground-service restrictions, 16 KiB alignment. Physical POCO F6 remains the final performance/voice-quality gate.
